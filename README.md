# List Installer – менеджер установки программ

## Описание

**List Installer** — это десктопное приложение для удобного управления списком программ и их установкой. Оно загружает данные из JSON-файла, показывает иконки, категории, размеры дистрибутивов и ссылки на установку, помогает отмечать уже установленные программы и отслеживать прогресс по всей базе.

Приложение подходит для каталогов программ, наборов утилит, рабочих наборов ПО и любых списков, которые нужно удобно просматривать и постепенно устанавливать.

## Основные возможности

- Загрузка списка программ из локального или удалённого JSON-файла
- Кэширование иконок в папке `src/icons/` для быстрого повторного показа
- Отображение категории, описания, веса и ссылки на скачивание
- Режим установки: постраничный просмотр неустановленных программ
- Режим списка: полный список со статусами ✅ / ❌
- Сброс прогресса и повторный запуск установки с нуля
- Автоматическая проверка и обновление прогресса после отметки установки
- Открытие ссылок в браузере одним кликом
- Поддержка нескольких ссылок на установку для одной программы
- Показывает процент готовности по всем программам

## Как это работает

При запуске приложение создаёт папки:

- `src/icons/` — кэш иконок
- `src/json/` — локальные JSON-файлы

Если `src/json/programs.json` отсутствует, программа скачивает его с удалённого URL и сохраняет локально. Затем данные из JSON разбираются и превращаются в список программ. Для каждой записи могут быть указаны:

- название программы
- URL иконки
- вес установщика
- категории
- описание
- список ссылок для установки
- флаг `IsDownloaded`

Пользователь работает в двух режимах:

- Режим установки — показывает текущую программу и позволяет перейти к следующей / предыдущей
- Режим списка — отображает весь список с фильтрами и удобным поиском по смыслу представления

## Требования

- Python 3.7 или новее
- Установленные зависимости:
  - `requests` — для загрузки JSON и иконок
  - `Pillow` — для обработки изображений
  - `tkinter` — входит в стандартную поставку Python

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python ListInstaller.py
```

### 3. Первый запуск

При первом запуске программа автоматически:

- создаст нужные папки
- загрузит JSON-файл
- скачает и кэширует иконки
- подготовит интерфейс к работе

## Структура данных JSON

Пример структуры файла `src/json/programs.json`:

```json
{
  "Google Chrome": {
    "Icon": "https://example.com/chrome.png",
    "Weight": 0.8,
    "Categories": ["Браузеры", "Рабочее"],
    "Description": "Браузер для работы и просмотра страниц.",
    "IsDownloaded": false,
    "URLs": {
      "Официальный сайт": [
        "https://www.google.com/chrome/"
      ],
      "GitHub": [
        "https://github.com/googlechrome/"
      ]
    }
  }
}
```

### Поля программы

- `Icon` — ссылка на изображение иконки
- `Weight` — вес файла в ГБ (может использоваться дробное число)
- `Categories` — список категорий
- `Description` — описание программы
- `IsDownloaded` — флаг отметки об установке
- `URLs` — словарь вида `Название метода: [ссылки]`

## Инструкция по использованию

### Режим установки

1. В верхней части отображается прогресс: `Готово: X/Y (Z%)`
2. Кнопки `<` и `>` позволяют переключаться между не установленными программами
3. Кнопка `Установить (~X MB/GB)` открывает окно со ссылками на установку
4. В окне установки можно выбрать несколько способов установки
5. После завершения установки нажмите `✔ Установлено`
6. Программа помечается как установленная и исчезает из текущего списка

### Режим списка

1. Нажмите кнопку `☰` для перехода в режим списка
2. В правой части можно включить фильтр `Только не установленные`
3. В левом верхнем углу доступен выпадающий список категорий
4. Список обновляется автоматически по выбранным фильтрам
5. Двойной клик или выбор элемента открывает окно установки программы
6. Нажмите `⊡`, чтобы вернуться к режиму установки

### Сброс прогресса

Кнопка `⟳` позволяет сбросить все отметки установки и начать обновление с нуля.

Перед сбросом приложение выводит подтверждение:

- `Вы уверены, что хотите выполнить это действие?`
- после подтверждения все программы будут помечены как не установленные

## Интерфейс и навигация

- `⟳` — сбросить прогресс установки
- `☰` — открыть список всех программ
- `⊡` — вернуться к режиму установки
- `<` / `>` — перемещение между программами
- `✔ Установлено` — пометить текущую программу как установленную
- `Только не установленные` — отфильтровать список в режиме списка
- `Сортировка ▾` — выпадающий список категорий

## Важные замечания

- Папка `src/icons/` используется как локальный кэш изображений. Для очистки кэша просто удалите содержимое этой директории.
- Если иконка не загрузилась, приложение отображает пустой placeholder или символ `❌`.
- Для некоторых серверов используются `User-Agent` и специальные заголовки запросов, чтобы уменьшить вероятность блокировки.
- При закрытии приложения появится запрос на сохранение прогресса, если данные были изменены.
- Список `URLs` поддерживает несколько способов установки для одной программы, например: официальный сайт, зеркало, GitHub, Mirosoft Store и т.д.

## Возможные проблемы и решения

- JSON не загрузился — проверьте ссылку, доступность сети и корректность файла
- Иконки не отображаются — некоторые сервера блокируют загрузку в фоне; иконка будет загружена при следующем запуске из кэша
- Ошибка `PIL.UnidentifiedImageError` — убедитесь, что ссылка указывает на изображение, а не на HTML-страницу
- Кнопки не реагируют — проверьте, что все зависимости установлены через `pip install -r requirements.txt`
- Приложение зависает во время загрузки — это нормальное поведение, так как иконки и данные подгружаются асинхронно в фоне

## Настройка под себя

### Изменение пути к JSON

В файле `ListInstaller.py` найдите:

```python
self.json_name = "src/json/programs.json"
```

и замените на свой путь или URL при необходимости.

### Изменение URL загрузки JSON

Если вы хотите загружать данные не с GitHub, а с вашего сервера, поправьте соответствующий параметр в методе `load_json()`.

### Изменение стилей интерфейса

Стили настраиваются в методе `setup_styles()`:

- `Green.TButton` — зелёная кнопка `✔ Установлено`
- `Blue.TButton` — синяя кнопка `Установить`
- `WhiteBlue.TButton` — белая кнопка с синим текстом
- `TransparentBlue.TButton` — прозрачная кнопка с синим текстом

### Изменение размера иконок

В методе `_load_icon_from_file()` можно изменить размер шаблона:

```python
img = img.resize((256, 256), resample_filter)
```
